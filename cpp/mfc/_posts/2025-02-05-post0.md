### 개요
몇 년 전 프로그램이 다운되는 현상이 발생해서 dump 파일과 로그, 메모리 등을 체크했는데 문제가 없었다.  
원인을 찾고 있었는데 현장에서 ``생산이 특정 개수 정도 되면 다운``되는 것을 알아냈다. (수천 개였던 것으로 기억하는데 알아낸 것도 대단하다.)  
해당 현상의 원인을 찾다가 ``GDI 개체``라는 것을 알게 되었다.  

---

### GDI 개체
#### GDI 개체란?
GDI(Graphics Device Interface) 개체는 Windows에서 그래픽을 그리는데 사용되는 구성 요소다.  
MFC에서는 클래스 형태로 제공되며 그래픽 요소를 표현할 때 사용된다.

#### GDI 개체 종류
1. Pen(CPen)
  선을 그리는 도구
2. Brush(CBrush)
  면을 채우는 도구
3. Font(CFont)
  글꼴을 지정할 때 사용됨
4. Bitmap(CBitmap)
  비트맵 이미지 데이터를 메모리에 저장하는 개체
5. Region(CRgn)
  클리핑 영역을 정의하는 개체
6. Palette(CPalette)
  색상 팔레트를 관리하는 개체
7. DC(Device Context, CDC)
  그래픽을 출력하기 위해 출력장치와 상호작용하는 인터페이스

### 다운되는 원인
GDI 개체수가 지속적으로 증가한다는 것은 보통 ``GDI 리소스 누수(GDI Leak)``가 발생하고 있다는 뜻이다.  
이는 심각한 문제로 이어질 수 있다.  
증가할수록 ``GUI 응답 속도 저하``, ``UI 깨짐`` 등의 현상이 나타날 수 있고,  
GDI 리소스가 부족하여 새로운 개체를 생성할 수 없게 되면 ``UI가 나타나지 않는 현상``, ``프로그램이 느려지거나 응답 없는 현상`` 등이 발생한다.  
마지막에는 프로그램이 강제 종료되는데 프로세스별로 GDI 개체수의 제한이 다르나, 보통 ``10,000개``로 제한되어있다.  
이것이 특정 회수를 실행했을 때나, 특정 시간이 흘렀을 때 다운되는 원인이다.

#### GDI 개체수 확인 방법
1. 작업관리자에서 확인하는 방법
   - ``Ctrl + Shift + Esc`` → ``세부 정보`` 탭 → ``첫 줄 우클릭`` → ``열 선택`` → ``GDI 개체`` 열 추가

2. 코드에서 확인하는 방법
   - ```c++
     int gdi_count = GetGuiResources(GetCurrentProcess(), GR_GDIOBJECTS);
     TRACE("GDI 개체 수: %d\n", gdi_count);

#### GDI 리소스 누수
GDI 개체수를 증가시키기 위해 테스트 코드를 작성했다.  
- ```c++
  {
    CBitmap* bmp = new CBitmap();
    bmp->LoadBitmap(IDB_BITMAP1); // 개체수 증가

    CDC* pDC = GetDC(); // 개체수 증가
    CDC* memDC = new CDC();
    memDC->CreateCompatibleDC(pDC); // 개체수 증가

    CBitmap* pOldBitmap = memDC->SelectObject(bmp);

    // 비트맵 사용

    memDC->SelectObject(pOldBitmap);
  
    // 1번
    bmp->DeleteObject(); // 개체수 감소
    delete bmp;

    // 2번
    memDC->DeleteDC(); // 개체수 감소
    delete memDC;

    // 3번
    ReleaseDC(pDC); // 개체수 감소
  }
  ```
    - 위 코드에서 1, 2, 3번 중 하나를 삭제할 때마다 GDI 개체가 원복되지 않고 **1 증가한다**.
    - 그러나 1번의 `bmp->DeleteObject();`나 2번의 `memDC->DeleteDC();`는 삭제해도 **증가하지 않는다**.  
      원인은 `CBitmap`과 `CDC` 클래스는 **소멸자에서 GDI 개체를 정리**하는 기능이 내장되어 있다.  
      `CBitmap::~CBitmap()` → 내부적으로 `DeleteObject()` 호출  
      `CDC::~CDC()` → 내부적으로 `DeleteDC()` 호출  
- ```c++
  {
    CBitmap bmp;
    bmp.LoadBitmap(IDB_BITMAP1); // 개체수 증가

    CDC* pDC = GetDC(); // 개체수 증가
    CDC memDC;
    memDC.CreateCompatibleDC(pDC); // 개체수 증가

    CBitmap* pOldBitmap = memDC.SelectObject(&bmp);

    // 비트맵 사용

    memDC.SelectObject(pOldBitmap);
    ReleaseDC(pDC); // 개체수 감소
  }
  ```
  - 따라서 위와 같이 지역변수로 선언한 경우 코드블럭을 벗어나면서 자동으로 개체를 정리한다.
